# Code of Conduct

Agently is a maintainer-directed project.

Participants are expected to communicate professionally, respect project
boundaries, and avoid abusive, harassing, discriminatory, or disruptive conduct.

The maintainer may close, hide, lock, or delete issues, pull requests,
discussions, or comments that are abusive, off-topic, disruptive, unsafe, or
outside the project's stated contribution policy.

This project is not currently accepting unsolicited contributions. Repeatedly
opening unwanted issues, pull requests, or governance debates after being asked
to stop may be treated as disruptive behavior.
