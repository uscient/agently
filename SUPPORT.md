# Support

Agently does not currently provide general public support.

This repository is maintainer-directed and is not accepting unsolicited feature
requests, support requests, or implementation consulting through GitHub Issues.

## Questions

For serious collaboration interest or integration discussion, contact the
maintainer through the published contact path:
https://github.com/xormania

## Security

Do not use public issues for security vulnerabilities. See `SECURITY.md`.

## Commercial or Organizational Interest

For organizational use, integration interest, or serious collaboration, contact
the maintainer first.
