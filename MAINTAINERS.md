# Maintainers

Agently is maintained by `xormania` under the `uscient` GitHub namespace.

## Authority

The maintainer is the final authority for:

- project direction
- doctrine
- command contracts
- release readiness
- contribution acceptance
- protected surfaces
- security response
- public positioning

Agents, tools, auditors, and collaborators may inspect, suggest, draft, or
implement invited work. They do not hold project authority.
