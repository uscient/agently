# Serena Codex Code Lane

The code lane is where Codex may use Serena MCP tools while performing a bounded
implementation, review, or refactor task.

This lane is governed by:

- the active Agently task;
- project doctrine and `AGENTS.md`;
- user permission;
- the selected Agently Serena profile;
- final Codex accountability for edits and tests.

Serena may help Codex find symbols, references, structure, and affected code.
In the `edit` profile, semantic edits or refactors may be appropriate only when
Codex is already authorized to edit project files.

Serena does not decide scope, authority, or acceptance.
